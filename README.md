# MapleStoryM-language

用爱发电,兴趣使然.

冒险岛 M 韩服汉化文件，支持游戏文本、剧情文本、潜能文本。

## 支持的 APP

点击下方配置链接，复制地址后在对应 APP 中导入。

| 🚀Shadowrocket | 🎈Loon | 🌀Quantumult X | 🌊Surge |
| --- | --- | --- | --- |
| 配置 → [模块](https://raw.githubusercontent.com/MapleRen/MapleStoryM-language/v4/Shadowrocket/msmcn.srmodule) | 配置 → [插件](https://raw.githubusercontent.com/MapleRen/MapleStoryM-language/v4/Loon/msmcn.plugin) | 重写 → [引用](https://raw.githubusercontent.com/MapleRen/MapleStoryM-language/v4/QuantumultX/msmcn.snippet) | 首页 → 修改 → [模块](https://raw.githubusercontent.com/MapleRen/MapleStoryM-language/v4/Surge/msmcn.sgmodule) |
